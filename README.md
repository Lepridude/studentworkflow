# StudentFlow

Студенческий планировщик на React, TypeScript и Vite. Приложение работает без бэкенда: профиль, задачи и события календаря сохраняются в `localStorage` текущего браузера.

## Требования

- Node.js 20+
- npm

## Локальный запуск

```bash
npm ci
npm run dev
```

Vite выведет локальный адрес приложения (обычно `http://localhost:5173`).

## Проверка

```bash
npm run build
```

Команда сначала проверяет TypeScript (`tsc --noEmit`), затем собирает production-версию через Vite.

## Основные возможности

- Главная панель со статистикой задач и ближайшими дедлайнами.
- Создание, выполнение и удаление задач.
- Календарь в режимах месяца, недели, дня и повестки.
- Создание и редактирование событий, повторение, напоминания, импорт и экспорт ICS.
- Двусторонняя связь задач и календарных дедлайнов.
- Поиск по задачам и событиям.
- Настройка имени и языка интерфейса (русский / английский).

## Структура проекта

```
src/
  App.tsx                  навигация и корневое состояние
  settings.ts              чтение и сохранение настроек профиля
  storage.ts               хранение задач
  calendarStorage.ts       хранение событий календаря
  taskCalendarSync.ts      синхронизация задач и событий
  components/              общие компоненты интерфейса
  pages/
    Dashboard.tsx          главная панель
    Tasks.tsx              список задач
    Calendar.tsx           календарь
  types/                   типы задач и событий
  utils/                   даты и расчёты по задачам
```

## Хранение данных

Данные сохраняются локально в браузере и не синхронизируются между устройствами. Очистка данных сайта или смена браузера может привести к их потере. Для межустройственной синхронизации потребуется серверное хранилище и API.
